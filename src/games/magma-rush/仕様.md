# マグマラッシュ（G3）

つばささんの案をもとにしたミニゲーム。下から迫るマグマから逃げながら、足場を跳び移って上へ登る縦スクロールのサバイバル。最後まで生き残った人が勝ち。

- 担当：野上（案：つばさ）
- 単体の確認：`/dev/magma-rush`（通信なし、キーボードで最大4人。F4 で全画面）
- 試合への登録（`src/platform/registry.ts`）：**まだ**。単体で遊んで OK が出たら1行足す

## ルール

| 項目 | 内容 |
|---|---|
| 勝敗 | マグマに触れたら脱落。足場から落ちてもマグマに沈んで脱落。**最後の1人になった時点で終わり**、その人の勝ち |
| 同時に脱落 | 最後の数人が同じ瞬間に飲まれたら、その人たちの引き分け |
| 脱落した人 | 画面から消え、操作できなくなる |
| 操作 | 左・右・ジャンプ（スマホの3ボタン）。足場の上でだけ跳べる |
| 画面の端 | 左右の壁の外へは出られない。画面の上端より上へも行けない |
| 足場 | 下からはすり抜け、上から乗れる。一度できた足場は時間で消えない |
| キャラどうし | ぶつからない（すり抜ける） |

## 試合の流れに合わせて変えた点

つばさ案の「3. ゲーム開始の流れ」は、第2期の試合の流れ（[docs/方針.md](../../../docs/方針.md)）に合わせて次のようにした。

| つばさ案 | このゲームでの扱い |
|---|---|
| タイトル画面・スタートボタン | 試合のホーム画面のスタートで代わりにする（ミニゲームごとのタイトル画面は作らない） |
| ルール説明を3秒表示 | 試合の進行がラウンドの始めに出す**ひと言の指示「マグマから逃げろ！」（3秒）**で代わりにする |
| 説明のあとに「3、2、1」 | カウントダウンは、ひと言の指示と**同時**に出す（Jump the highest とそろえた。別々にすると始まるまで6秒かかる） |
| 結果画面 | 試合のミニリザルト（勝った人のライトが点く）で代わりにする。ゲームの中では FINISH を2秒出すだけ |

## しくみ

- **マグマ＝画面の下端**：カメラ（縦スクロール）が上がり、マグマは画面の下端にくっついて一緒に上がる。マグマの表面は時間とともに画面の下の方へせり上がる（16px → 40秒で150px）
- **速さ**：30 px/秒から始まり、40秒で 150、58秒で 260 px/秒（登りきれない速さ）になって必ず勝負がつく
- **スタート**：画面の横いっぱいの岩場に全員が並ぶ。マグマが岩場に届くまで約3.5秒
- **足場の生成**（`stage.ts`）：段ごとに下から上へ作る
  - 最初の3段は1段に4個（登りやすく）。登るほど 3個 → 2個 → 1〜2個 に減る
  - 段の高さの差は 60〜85px → 85〜105px、横の隙間は「重なるくらい」→ 30〜90px に広がる（4000px 登ったところで一番難しくなる）
  - **どの足場にも、1つ下の段の足場からジャンプで届く**（高さの差 105px・横の隙間 90px まで。ジャンプの最高到達点は約140px）。届くことはテストで物理を動かして確かめている
  - 画面の端に寄った足場の次は、中央へ向かいやすくして左右に偏らないようにしている
  - 乱数の種が同じなら同じステージになる（ラウンドごとに種を変える）
- 背景：峡谷の岩壁（足場より遅く流して奥行きを出す）。色は `src/theme.ts` の `canyon`・`magma`

## ファイル

| ファイル | 中身 |
|---|---|
| `constants.ts` | 大きさ・速さ・足場の生成の数値（遊んで調整する値はここ） |
| `stage.ts` | 足場の生成（純粋な関数） |
| `step.ts` | 1コマ分の処理：スクロール・足場の追加・キャラの物理・マグマで脱落・勝敗（純粋な関数） |
| `render.ts` | 描画（峡谷・足場・キャラ・マグマ） |
| `MagmaRushRound.tsx` | 1ラウンド分の画面（カウントダウン → ゲーム → FINISH → 勝った人を返す） |
| `miniGame.ts` | ミニゲームとして登録するための情報（id・名前・ひと言の指示） |
| `DevMagmaRushPage.tsx` | 開発用ページ `/dev/magma-rush` |

使っている部品：スクロール（`scroll.ts`）・足場（`platforms.ts`）・脱落と勝敗（`survival.ts`）・キャラの物理（`jumper.ts`。このゲームのために足した）。キャラの絵・カウントダウン・FINISH・音は Jump the highest のものを使っている。
