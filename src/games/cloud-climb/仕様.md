# 雲のぼり（G2）

- 担当：野上（Claude が実装）
- 単体の確認：`/dev/cloud-climb`（通信なし、キーボードで最大4人）。スマホで遊ぶには、ホスト画面の URL に `?game=cloud-climb` を付ける
- ラウンド開始のひと言：「生き残れ！」

## 概要

縦スクロールの画面で雲を登る。途中で雷と鳥が出て、当たったら脱落。最後まで生き残った人が勝ち

## 共通ルール（全ミニゲーム）

- コントローラーは Jump the highest と同じ。操作は左・右・ジャンプだけ。ひと言の指示はコントローラーには出さない（PCの画面だけ）
- ぶつかったら弾け飛ぶ（`src/engine/jumperCollisions.ts`）
- 1ラウンドの長さ：スクロールなし 10〜15秒／スクロールあり 15〜20秒。スクロールの速さを変えたいときは野上さんに数字を出して承認をもらう
- 部品は `docs/部品一覧.md` にあるものを使う。物（コイン・毒キノコ・鳥・雷）は `src/engine/objects.ts`

## ルール・しくみ

- キャラどうし：Jump the highest と同じ（頭に乗れる・横から弾かれる）。**頭の上に乗っている人は、下の人が横に動いた分だけ一緒に運ばれる**（`src/engine/carry.ts`。2026-10-12 追加）
- 勝敗：画面の下に置いていかれる・雷に打たれる・鳥に当たると脱落。最後の1人が勝ち。同時に脱落したら引き分け
- スタート：画面の横いっぱいの雲の島に全員が並ぶ。カメラが上へ進み、雲を跳び移って登る
- 雲の足場（`stage.ts`）：マグマラッシュと同じ作り（どの雲にも1つ下の段からジャンプで届く。登るほど数が減り、狭く・離れる）。**見た目は岩の足場と同じ形で、色だけ白＋水色の影**（野上さん承認 2026-10-12）。背景は空の単色に、遅く流れる水色の遠い雲（足場の白と見分けるため）
- 雷（`hazards.ts`）：画面の上に雷雲が光り、狙った人の近く（±40px）に点線と「!」の予告 0.8秒 → 落下 0.3秒。柱は画面の上から下まで。予告のあいだは当たらない
- 鳥：画面の端に「!」が 0.8秒出たあと、狙った人の体の高さを横切る（220 px/秒）。予告のあいだは当たらない。ジャンプで越える
- 雷・鳥は画面に固定（スクロールで流れない）。同時に出るのは2つまで。最初は 6秒後、そのあと 3.2秒おき → 2.0秒おき（16秒で）
- 脱落の効果音は原因ごとに別（雲から落ちた／雷／鳥）。予告は「ピッ・ピッ」、雷が落ちる音あり（`sounds.ts`）

## ファイル

`constants.ts`（数値）・`stage.ts`（雲の生成）・`hazards.ts`（雷と鳥）・`step.ts`（1コマ）・`render.ts`（絵）・`sounds.ts`（音）・`CloudClimbRound.tsx`・`miniGame.ts`・`DevCloudClimbPage.tsx`

## 調整ログ

測定方法：4人（上手2・普通1・下手1のボット。席を回す）で200試合。ボットのコードはプロジェクトの外に置いた（`src/games/magma-rush/ボット計測.md` が見本。雷はよける、鳥は近づいてから跳ぶ動きを足した）。

### 1周目（2026-10-12）

最初の値（スクロール 25→105→200、鳥 260px/秒、最初の雷・鳥 5秒後）：1ラウンド 中央12.0秒（10.0〜14.2秒）。目標の15〜20秒より短い。上手のボットの10秒以内の脱落 38%。

問題点（フィードバック）と直したこと：
1. 上手のボットが鳥に当たりすぎる → 調べたら**ボットが、頭の上を通る鳥に自分から跳んで当たっていた**（ボットの判断ミス）。ボットを「立ったままで当たる高さのときだけ跳ぶ」に直した
2. 鳥が速くて、跳ぶタイミングの幅が狭い（260px/秒で約0.18秒）→ **220 px/秒**に遅くした
3. 最初の雷・鳥が早い → **5秒後 → 6秒後**
4. 1ラウンドが短い → スクロールを遅くする案を測った（下の表。**野上さんの承認待ち**。承認が出るまで constants.ts は元の値）

スクロール案の比較（鳥 220・最初6秒の条件。長さは中央値と25〜75%の幅）：

| 案（開始 → 加速して上限） | 1ラウンドの長さ | 上手の勝率 | 下手の勝率 | 雷・鳥で脱落 |
|---|---|---|---|---|
| 現在 25 → 105 → 200 | 12.3秒（10.7〜14.1） | 34% | 4% | 19% |
| 20 → 90 → 170 | 13.9秒（11.8〜16.0） | 36% | 6% | 27% |
| 16 → 70 → 140 | 15.3秒（13.1〜17.7）※鳥260の測定 | 32% | 9% | 37% |
| **16 → 64（加速3）→ 130（加速5）** | **16.3秒（13.9〜19.7）** | 33% | 12% | 41% |

※勝率は1人あたり。25%が全員同じ。腕の差が出ているほど上手と下手が離れる。

気づいたこと：遅くするほど、雷・鳥が脱落の4割を占めて腕の差が縮む（下手の勝率が上がる）。雷・鳥の頻度は次の周で下げて、登る腕の差が勝負を決めるようにする。
