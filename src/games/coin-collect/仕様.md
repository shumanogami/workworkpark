# コイン集め（G4）

- 担当：野上（Claude が実装）
- 単体の確認：`/dev/coin-collect`（通信なし、キーボードで最大4人）。スマホで遊ぶには、ホスト画面の URL に `?game=coin-collect` を付ける
- ラウンド開始のひと言：「コインをあつめろ！」

## 概要

横スクロールの画面でコインを集める。点数は画面に出さず、内部で数える。一番多く集めた人が勝ち

## 共通ルール（全ミニゲーム）

- コントローラーは Jump the highest と同じ。操作は左・右・ジャンプだけ。ひと言の指示はコントローラーには出さない（PCの画面だけ）
- ぶつかったら弾け飛ぶ（`src/engine/jumperCollisions.ts`）
- 1ラウンドの長さ：スクロールなし 10〜15秒／スクロールあり 15〜20秒。スクロールの速さを変えたいときは野上さんに数字を出して承認をもらう
- 部品は `docs/部品一覧.md` にあるものを使う。物（コイン・毒キノコ・鳥・雷）は `src/engine/objects.ts`

## ルール・しくみ

| 項目 | 内容 |
|---|---|
| 勝敗 | **18秒**の制限時間で終わり。コインを一番多く集めた人が勝ち。同数なら引き分け（点数は画面に出さない。内部は `score.ts`） |
| 脱落 | なし。地面は途切れず、落ちる穴もない |
| 操作 | 左・右・ジャンプ（スマホの3ボタン）。足場の上でだけ跳べる |
| スクロール | 横スクロール。**60 px/秒から始まり、11秒で最高の 170 px/秒**（以降一定。18秒で約2,450px）。キャラの走る速さ（208 px/秒）より遅くして、追いつけるようにした。共通の初期設定（最高500）は速すぎた（野上さん 2026-10-12） |
| 動く壁 | 画面の左端は壁。スクロールに遅れた人は押されて運ばれる（ゲームから外れない）。**画面の右の1/3には行けない**（右端に居座ると、流れてくるコインを総取りできるため） |
| キャラどうし | Jump the highest と同じ当たり判定（頭に乗れる・横から弾かれる） |
| スタート位置 | 並び順はラウンドごとにシャッフル（右ほど最初のコインに近くて有利なため） |
| 効果音 | ジャンプ・弾かれたとき（共通）、コインを取ったとき（`sounds.ts`。高い2音の「チャリン」）。取った場所に小さな光 |

### コインと足場の並べ方（`stage.ts`）

- 横幅480pxの「ブロック」を5種類用意し、乱数で並べて道を作る。**同じ種類は続かない**。最初は必ず「地面の列」。左右を反転することもある。ブロックの間にランダムで0〜40pxの隙間
- どのブロックも**地面・中段・高段の2〜3段**にコインを置く（1段だけだと、一番右の人が総取りするため）
- 高さは地面 440・中段 340・高段 240（段差100px。ジャンプで届く範囲は105px以内）。階段だけ60pxずつ

| ブロック | 中身 |
|---|---|
| 地面の列（ground） | 地面5枚 + 中段の小さな足場に3枚 |
| アーチ（arch） | 山なりの5枚（跳ばないと取れない）+ 地面4枚 + 中段の足場に3枚 |
| 中段の長い足場（midPlat） | 地面4枚 + 中段4枚 + その上の高段3枚 |
| 高段の宝（treasure） | 中段2枚 + 高段8枚 + 地面2枚 |
| 階段（stairs） | 60pxずつ上がる3段に各2枚 + 地面3枚 |

## 調整ログ

自動のボット（腕前の違う4人：上手2・普通1・下手1）で、1回につき300試合を測る。ボットのコードはプロジェクトの外に置く。

### 1周目（2026-10-12）

| 版 | 勝ち数（上手A／上手B／普通／下手） | 引き分け | 1位と2位の差（枚） | 1試合のコイン |
|---|---|---|---|---|
| ① 1ブロック1段・スタート位置固定 | 10／25／7／52（100試合） | 6% | 11.8 | 41 |
| ② スタート位置シャッフル + ボットが取り合いを避ける | 93／102／58／43 | 1.3% | 21.4 | 41 |
| ③ 1ブロックに2〜3段（現在） | 99／108／51／37 | 1.7% | 16.6 | 52 |

- ①：スタート位置が右の人が最初のコインを先取りし、下手が一番勝った → 位置をシャッフルに
- ②：腕前が反映された（上手2人で65%）。ただし1位が全体の半分近くを取り、他の人はほぼ0枚の試合が多い（一番右の人が総取り）→ 1ブロックに複数の段を置いて、人が散らばるように
- ③：上手2人で69%、下手12%。引き分けは少ない。ボットが左端の壁にいた時間は平均9.5%（全員が壁に押される状態にはなっていない）。**課題**：1位と2位の差が大きい（16枚。例：46・0・0・0 のように1人が総取りする試合が残る）。原因はまだ未確認（2周目で、取り合いの様子とスクロールの速さの影響を測る）

### 2周目（2026-10-12）

野上さんが遊んで「スクロールが速すぎて、キャラが追いつけない」→ **スクロールを遅く**した（共通の初期設定 最高500 → 60から始まり最高170 px/秒）。

| 版 | 勝ち数（上手A／上手B／普通／下手） | 引き分け | 1位と2位の差（枚） | 3枚以下で終わった人（普通／下手） |
|---|---|---|---|---|
| スクロールを遅く | 101／110／47／33（300試合） | 3.0% | 12.4 | ― |
| + 地面のコインを増やす（全ブロックで途切れなく） | 59／80／97／63 | 0.3% | 20.2 | 42%／49% |
| 右端の制限なし・地面そのまま（再測定、200試合） | 58／57／50／30 | 2.5% | 13.6 | 41%／51% |
| **右の1/3に行けない（採用）** | 55／56／47／35 | 3.5% | 10.9 | 39%／56% |
| 右の1/2まで | 51／46／55／44 | 2.0% | 11.6 | 47%／52% |

- 遅くしたことで、左端の壁に押されていた時間は 9.5% → 2.8% に減り、1位と2位の差も 16 → 12 枚に縮んだ
- **わかったこと**：全員が画面の右端に集まり、右端にいる人が流れてくるコインを総取りしていた（ある試合で、右端の人が47枚、後ろの人は0枚）。右端に居座るのが一番得だった
- 地面のコインを増やすと、総取りがひどくなり、腕前の差も出なくなった（上手の勝率 46%）ため、やめた
- 右の1/3に行けないようにすると、1位と2位の差が最小になった（10.9枚）。上手の勝率は約56%、下手は約17%
- **残る課題**：下手なボットの56%が3枚以下で終わる。「前にいる人が先に取る」ことは変わらないため。人間が遊んでの確認が必要
