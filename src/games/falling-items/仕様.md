# 落下物避け（G5）

- 担当：野上（Claude が実装）
- 単体の確認：`/dev/falling-items`（通信なし、キーボードで最大4人）。スマホで遊ぶには、ホスト画面の URL に `?game=falling-items` を付ける
- ラウンド開始のひと言：「コインを集めろ！」

## 概要

スクロールなし。上からコインと毒キノコが降ってくる。コインを取り、毒キノコは避ける。**コインの点数を一番多く集めた人が勝ち**（同点なら引き分け）。キャラが地面で押し合い・弾かれるので、コインの取り合いで「わいわい」する

## 共通ルール（全ミニゲーム）

- コントローラーは Jump the highest と同じ。操作は左・右・ジャンプだけ。ひと言の指示はコントローラーには出さない（PCの画面だけ）
- ぶつかったら弾け飛ぶ（`src/engine/jumperCollisions.ts`）
- 1ラウンドの長さ：スクロールなし 10〜15秒／スクロールあり 15〜20秒。スクロールの速さを変えたいときは野上さんに数字を出して承認をもらう
- 部品は `docs/部品一覧.md` にあるものを使う。物（コイン・毒キノコ・鳥・雷）は `src/engine/objects.ts`

## ルール・しくみ（値は `constants.ts`）

- 長さ：**12秒**。スクロールなし。地面・壁・空は Jump the highest と同じ
- 点数：コイン **＋10**、毒キノコ **－30**（0 未満にはならない）。同じ物に2人が同時に触れたら、物の中心に近い人が取る
- 降る物：コイン8：毒キノコ2。画面の上の外から、壁の内側のどこかに降る。地面に着くと消える
- 降り方：間隔は **0.3秒 → 0.1秒**（ラウンドの終わりに向けて詰まる。4人のときの値で、人数が多いほど密に、最低2人分）。落ちる速さは **秒速150 → 350px**（物ごとに ±15% ばらつく）。**4割は前の物の近く（±60px）に固めて降る**＝同じ場所に人が集まって取り合いになる
- 点数の表示：ラウンド中は出さない。終了（FINISH）の瞬間に、画面の上に各自の点数を並べる（一番高い人は黄色）
- 動き：キャラの物理は `jumper.ts`、ぶつかりは `jumperCollisions.ts`、取る処理は `score.ts`（部品）
- 音：コインは高い「ピン」、毒キノコは低い「ブッ」（`sounds.ts`）。ジャンプ・弾かれは共通の音
- 1コマの進め方は `step.ts`（純粋な関数。`step.test.ts` で13項目をテスト）、絵は `render.ts`

## 調整ログ

自動のボット（上手2・普通1・下手1。席と腕前は試合ごとにシャッフル）で、1回につき200〜300試合を測った。ボットの計測コードはプロジェクトの外に置いてある（`src/games/magma-rush/ボット計測.md` と同じやり方）。ボットは、毒キノコが頭上に来そうなら逃げ、一番早く落ちてくるコインへ向かう。上手いボットだけは、頭上の高いコインへ跳ぶ

### 1周目（初期案：12秒、間隔 0.5→0.2秒、一様に降る）N=200

| 項目 | 数字 |
|---|---|
| 引き分け | 12.5% |
| 勝ち（1人あたり） | 上手 45.5%／普通 16.0%／下手 10.0% |
| 平均点 | 上手 47／普通 30／下手 23 |
| 1位と2位の点差（中央値） | 20（コイン2枚） |
| 弾かれ／試合 | 21回 |
| コインの取り合い／試合 | 0.3回 |

フィードバック：① 引き分けが多い（枚数が少なく点差が小さい） ② コインの取り合いがほとんど起きない（バラバラに降るので、人が散らばって取れてしまう）

直したこと：降る数を増やした（間隔 0.4→0.15秒）。コインを前の物の近くに固めて降らせるようにした（4割）

### 2周目（直した後）N=300

| | 間隔 0.4→0.15（12秒） | 間隔 0.3→0.1（12秒）**採用** | 間隔 0.32→0.12（14秒） |
|---|---|---|---|
| 引き分け | 13.0% | 14.3% | 11.7% |
| 勝ち（上手／普通／下手） | 43／18／9% | 42／22／10% | 43／19／8% |
| 最下位が0点 | 29.7% | 18.7% | 16.3% |
| 弾かれ／試合 | 22回 | 22回 | 26回 |
| 頭に乗る／試合 | 4.1回 | 4.2回 | 4.9回 |
| コイン取得／試合 | 21.7枚 | 28.3枚 | 31.2枚 |

分かったこと：
- 弾かれは毎試合20回以上、頭に乗るのも4回前後あり、押し合いのわいわいは十分
- 最下位が0点（何も取れない人がいる）は、密度を上げて 30% → 19% に減った
- **引き分けは密度や長さを変えても11〜14%で下がらない**。主な原因は、同じ動きをする上手ボット2人の同点（コインが10点刻みで、上位は2〜3枚差に収まる）。実際の人間は動きにばらつきがあるので、これより少なくなる見込み
- ボットの腕前差は人間より極端（下手ボットは半分近く見落とす）。勝ち率が上手に偏るのはその影響

未決定（野上さんに相談）：引き分けをもっと減らすか。案は「同点なら、最後にコインを取った人が勝ち」（全員0点のときだけ引き分け）
