# 共通部品への依頼（落下物避け）

共通ファイルは触らない決まりなので、足したいものをここに書く。

## 背景（青空・太陽・雲・草の地面・壁）の描画を部品にしたい

- 何を：`src/game/render.ts` の `drawSun`・`drawCloud`・地面と壁の描画を、`export` して使い回せるようにする（または `src/engine/` に背景の部品を足す）
- なぜ：落下物避けでは Jump the highest と同じ背景が要るので、`src/games/falling-items/render.ts` に同じコードをコピーしている（約50行）。コイン集めなど、ほかのゲームでも同じコピーが増える
- 急ぎではない。コピーのままでも動く

## 頭の上に乗った人を、下の人の横移動で運ぶ処理を部品にしたい

- 何を：`src/engine/` に、「下にいる人から順に動かし、上に乗っている人（`standingOn` が人の `playerId`）へ下の人の横の移動量を足す」処理を足す（`jumperCollisions.ts` の隣に新しいファイルでよい）
- なぜ：Jump the highest にはあるが、共通の部品にはない。落下物避けでは `step.ts` に自前で実装した（約15行）。キャラが乗れるほかのゲームでも同じものが要る
- 急ぎではない。コピーのままでも動く
