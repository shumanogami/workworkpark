# 部品一覧（新しく作る前に読む）

このリポジトリには、**複数のゲームで使い回せる部品**がすでにある。新しいゲームや機能を作るときは、まずここを確認し、**同じ処理を作り直さずに部品を使う**こと。足りない機能は、部品の側に足す（テストも一緒に）。

- 部品の置き場所：`src/engine/`（ゲーム共通）、`src/audio/`（音）
- どの部品も、特定のゲーム（`src/game/` の「Jump the highest」）の物理・描画に**依存しない**。部品（`src/engine/*.ts`）から `src/game/` を import しない（例外：開発用ページ `*DemoPage.tsx` は、開発用のキーボード操作 `src/game/keyboard.ts` を使ってよい）
- 計算はすべて**純粋な関数**（画面・通信・音に触らない）で、テストが付いている。使い方の例はテスト（`*.test.ts`）と開発用ページを見るのが早い

## ⚠ 座標の向きに注意

| 場所 | 座標の向き |
|---|---|
| `src/engine/` の部品 | **キャンバスと同じ**：左上が原点、**下向きが正**。x・y は長方形の左上 |
| `src/game/`（Jump the highest） | 物理は**上向きが正**（`y` は地面からの足元の高さ）。描くときに画面座標へ変換している |

`src/game/` の物理（重力・ジャンプ・頭に乗る・横衝突）は Jump the highest 専用。新しいゲームでそのまま使うものではない。

### スクロール（`scroll.ts`）

カメラがゲームの世界を一定の向きに進む方式。キャラや足場はワールド座標で置き、描くときに `toScreen` で画面座標に変える。

- 設定 `ScrollConfig`：`axis`（`'horizontal'`／`'vertical'`）、`direction`（横は 1＝右へ、縦は 1＝上へ）、`initialSpeed`、`phases`（速さの段階）
- 段階 `SpeedPhase`：`{ acceleration, maxSpeed }`（その速さまで加速）または `{ holdSeconds }`（今の速さを保つ）
- 初期設定（芦田が試して決定）：
  - `DEFAULT_HORIZONTAL`：60 → 16秒で300 → 20秒で500
  - `DEFAULT_VERTICAL`：40 → 16秒で200 → 20秒で300 → 25秒まで300 → 45秒で400
- 主な関数：`createScroll` → 毎コマ `stepScroll(state, config, dt)`。`toScreen`（ワールド→画面）、`visibleRange`（画面に入っている範囲）、`wrapOffset`（くり返し背景）、`speedAt`・`offsetAt`・`topSpeed`
- 進んだ距離は時間から正確に計算するので、何コマに分けて進めても結果は同じ

### 1ラウンドの共通の枠（`src/platform/RoundShell.tsx`）

- 新しいミニゲームは、`RoundGame`（状態の作り方 `create`・1コマの進め方 `step`・絵 `render`・決着 `isFinished`・勝者 `winners`・出来事 `events`・音 `sfx`）を書いて `<RoundShell game={...} {...props} />` に渡すだけ。カウントダウン・FINISH・BGM・F4全画面・ループの止め方は枠が行う
- 座標は 960×540（canvas は2倍）、物理は固定 1/60 秒（`ROUND_DT`）
- 出来事は文字列で返す（例：`'jump'`・`'bounce'`・`'magma'`）。`'jump'` と `'bounce'` の音は初めから入っていて、ほかは `sfx` の表で音に結びつける
- 見本：`src/games/magma-rush/MagmaRushRound.tsx`
- コントローラーは全ゲーム共通（左・右・ジャンプ）。ゲームごとのひと言の指示は PC の画面だけに出す

### キャラの物理（`jumper.ts`）

- `createJumper(x, y, 大きさ)`、毎コマ `moveJumper(キャラ, 入力, dt, 設定)` → `updateOnPlatforms`（足場の部品）の順に呼ぶ
- 足場に乗っている（`standingOn` が null でない）ときだけ跳べる。押しっぱなしでは跳び続けない。着地の 0.1 秒前までに押したジャンプは着地の瞬間に跳ぶ
- 設定 `JumperConfig`：重力・ジャンプの初速・横の速さと加速度（地上・空中）・落ちる速さの上限・動ける範囲（`minX`・`maxX`）。`DEFAULT_JUMPER` は Jump the highest と同じ跳び心地（最高到達点 約140px）
- 入力が `undefined`（切断中・未着）は何も押していない扱い。`playerId` などゲーム側で足した項目はそのまま引き継ぐ
- 弾かれている間（`stunTime` > 0）は、左右もジャンプも受け付けず、横の勢いのまま飛ぶ
- キャラどうしの当たり判定は `jumperCollisions.ts`（下の節）。`jumper.ts` だけではキャラどうしはすり抜ける

### キャラどうしの当たり判定（`jumperCollisions.ts`）

- 毎コマ：全員を `moveJumper` → `updateOnPlatforms` で動かした後、`carryRiders`（頭の上の人を運ぶ。下の節）→ `resolveJumperCollisions(動く前の全員, 運んだ後の全員, 設定)` の順に呼ぶ（全員が同じ大きさの四角で、`playerId` を持つこと）
- 上から重なったら頭の上に立つ（`standingOn` に下の人の `playerId`）。頭の端に浅くかかっただけなら横へ滑り落ちる。下の人が跳べば一緒に持ち上がる。3人以上の積み重なりもOK
- 横から重なったら、どちらかが動いていれば反対向きの斜め上へ弾き、`stunTime` の間は操作を受け付けない。両方止まっていれば押し離すだけ。壁の外へは出ない
- 設定 `JumperCollisionConfig`：動ける範囲・弾く速さ・操作できない時間・「動いている」の下限・頭に立てる最小の重なり。`DEFAULT_COLLISION` は Jump the highest と同じ値（キャラの大きさ 40px のとき）
- 脱落した人は、渡す配列から外す（ぶつからない）

### 頭の上の人を運ぶ（`carry.ts`）

- `carryRiders(動く前の全員, 動いた後の全員, minX, maxX)`：頭の上に立っている人（`standingOn` に下の人の `playerId`）を、下の人がこのコマで横に動いた分だけ一緒に動かす。動ける範囲（`minX`〜`maxX`）の外へは出さない
- `resolveJumperCollisions` の**前**に呼ぶ（運ばれた先で、もう一度頭の上に立たせるため）。これを呼ばないと、下の人が歩いても上の人は置いていかれる
- 全ミニゲーム（マグマラッシュ・雲のぼり・コイン集め・落下物避け・おしくらまんじゅう）で使用中。新しいゲームでも、キャラが頭に乗れるなら必ず呼ぶ

### 物の絵（`objects.ts`）

- `drawCoin`・`drawPoisonMushroom`・`drawBird`・`drawThunderCloud`・`drawThunder`：ドット絵を描く（`t` は経過秒。きらめき・羽ばたきなどの動きに使う）
- `OBJECT_SIZE`（絵の大きさ）、`hitRect(種類, x, y)`（絵より少し小さい当たり判定）、`boltHitRect`（雷の柱）
- 雷：`thunderPhase(落ち始めた時刻, 今)` → `'idle'`／`'warning'`（予告 0.8 秒）／`'strike'`（落雷 0.3 秒）

### 足場（`platforms.ts`）

- `Platform`：`{ id, x, y（上面）, width, height }`。`Body`（乗るもの）：`{ x, y, width, height, vx, vy, standingOn }`
- 毎コマ：足場を動かす → キャラを重力などで動かす → `updateOnPlatforms(前のキャラ, 動いた後のキャラ, 前の足場, 今の足場)`
- 乗っている間は足場の上に固定し、足場が横・上下に動けば一緒に運ぶ。速く落ちても、上がってくる足場とすれ違っても、すり抜けない
- 端に4px（`MIN_PLATFORM_OVERLAP`）未満しかかかっていなければ乗らない。ジャンプ（`vy < 0`）で離れる
- `patrol(from, to, speed, t)`：足場を往復させる位置

### ポイント（`score.ts`）

- `createScores(playerIds)`、`addPoints(scores, playerId, points)`（マイナスも可。**0 未満にならない**）
- `Item`：`{ id, x, y, width, height, points, kind? }`（`kind` は見た目・効果音の切り替え用）
- 毎コマ：`collectItems(キャラの一覧, 残っているアイテム)` → `{ remaining, pickups }`、`applyPickups(scores, pickups)`
- 同じアイテムに2人同時に触れたら、アイテムの中心に近い人が取る

### 脱落・勝敗（`survival.ts`）

- `createSurvival(playerIds)`、`eliminate(state, playerIds, 時刻, 理由)`
- `Hazard`：`{ id, x, y, width, height, cause }`（マグマ・毒など）。`touchingHazards(キャラ, 危険物)` で触れた人を調べる
- `isOutside(体, 画面, 余白?)`：画面の外へ完全に出たか（スクロールに置いていかれた人など）
- 脱落した人は `isAlive` / `onlyAlive` で外し、**描かない・入力を受け付けない・動かさない**（どう扱うかはゲーム側）
- 勝敗：`judgeSurvivor`（残り1人で勝ち。全滅なら最後に脱落した人たちの引き分け。1人で始めたら脱落まで決まらない）、`judgeAtTimeUp`（制限時間なら生き残り全員の引き分け）、`ranking`（生き残りが1位、脱落が遅いほど上位、同時は同順位）
- Jump the highest の「一番高い人が勝ち」は別物（`src/lib/judge.ts`）

### 音（`src/audio/`）

- 素材ファイルは使わず、Web Audio API で音を作っている（素材サイトの利用規約の問題を避けるため。OpenTracks は Web ゲームでの利用が規約に触れるおそれがあった）
- 効果音：`playJump`・`playBounce`・`playDecide`・`playCountdownTick`・`playCountdownGo`・`playFinish`・`playMagmaDeath`（マグマに飲まれたとき。ノイズを使った「ジュワッ」）・`playDrumroll`（総合優勝の発表前のドラムロール）・`playFanfare`（総合優勝のファンファーレ）
- BGM：`startBgm`・`stopBgm`（利用者の最初の操作より前に呼んでも、操作されたときに流れ始める）。`startBgm(VICTORY_SCORE)` のように楽譜を渡すと別の曲になる（省くとゲーム中の曲 `GAME_SCORE`）。楽譜は `src/audio/score.ts`
- ミュート：`setMuted`・`isMuted`・`onMutedChange`、M キー（`installAudioUnlock` で設定済み）。画面用の `SoundToggle` コンポーネントあり

## まだない機能（必要になったら部品に足す）

- **動く壁**（画面の端がスクロールで進み、遅れた人を押す）。`moveJumper` は壁に当たると横の速さを 0 にするため、動く壁を `minX` に渡すと押された人が動き出せない。コイン集めは `step.ts` で自前に処理している（2本目が必要になったら部品に足す）
- **背景の絵**（青空・太陽・雲・草の地面）。落下物避けとおしくらまんじゅうが、Jump the highest（`src/game/render.ts`）の描き方をそれぞれコピーしている
- 壁・ブロックなど**横や下からもぶつかる足場**（今の足場は上から乗るだけ）
- 「下を押して足場から飛び降りる」操作（スマホに「下」のボタンがないため未実装）
- 足場・アイテム・危険物を**自動で並べる**処理（開発用ページでは番号から決まった配置を仮に作っている）
- 見た目（雲・マグマなどの絵）。部品は当たり判定と処理だけで、描き方はゲームごとに決める
