# 開発環境の確認

メンバー全員のPCで、同じ条件で開発・動作確認できるかを確かめるためのチェック表。
導入手順そのものは [README.md](../README.md) を参照。

## 1. 全員が用意するもの

| 必要なもの | 求める条件 | 確認方法 | 補足 |
|---|---|---|---|
| Node.js | **24系**（`.nvmrc` と `package.json` の `engines` で指定） | `node -v` → `v24.x.x` | JavaScriptを動かす土台。版が違うとビルド結果が変わることがある |
| npm | Node.js に付属するもの | `npm -v` | 部品（パッケージ）を入れる道具。別途インストールは不要 |
| Git | 最新版でよい | `git --version` | 変更履歴の管理 |
| GitHub アカウント | リポジトリ `shumanogami/workworkpark` の Collaborator（共同編集者） | リポジトリに push できるか | 招待は野上さんから |
| GitHub CLI（`gh`） | あると便利（任意） | `gh auth status` | PRの作成をコマンドで行う道具。Claude Code が使う |
| 依存パッケージ | `package-lock.json` どおり | `npm ci` がエラーなく終わる | `git pull` で `package-lock.json` が変わったら再実行 |
| スマホ | iPhone または Android（ブラウザが動けばよい） | 公開URLの `/controller` が開ける | 実機テスト用 |

## 2. 環境変数（各自の `.env.local`）

`.env.example` をコピーして `.env.local` を作り、次の2つを入れる。**`.env.local` はGitに含めない**（`.gitignore` で除外済み）。

| 変数名 | 値 | 入手方法 |
|---|---|---|
| `VITE_SUPABASE_URL` | `https://xxxx.supabase.co` 形式のURL | 野上さんからチャットで受け取る |
| `VITE_SUPABASE_ANON_KEY` | `sb_publishable_` で始まるキー | 野上さんからチャットで受け取る |

- 変数名は `ANON_KEY` だが、値には **publishable キー**を入れる（旧 `anon` キーは使わない）。Vercelに登録済みの名前に合わせている
- 以前の名前 `VITE_SUPABASE_PUBLISHABLE_KEY` で作っていた人は、名前だけ書き換える（値はそのまま）
- 変更したら `npm run dev` を再起動する

## 3. 外部サービス（野上さんが管理）

| サービス | 状態 | 設定内容 |
|---|---|---|
| Supabase | 作成済み | プロジェクト `workworkpark`（東京リージョン・無料プラン） |
| Vercel | 連携済み | 公開URL https://workworkpark.vercel.app 。環境変数 `VITE_SUPABASE_URL`・`VITE_SUPABASE_ANON_KEY` を Production・Preview の両方に登録 |

他のメンバーは、Supabase・Vercel のアカウントがなくても開発できる。

## 4. 確認コマンド

ターミナル（Windows は PowerShell）で、リポジトリのフォルダに移動してから順に実行する。

```sh
node -v          # v24.x.x なら OK
npm -v
git --version
gh auth status   # 任意。Logged in と出れば OK
npm ci           # エラーなく終われば OK
npm run build    # 「built in …」と出れば OK
npm test         # 失敗（failed）がなければ OK
npm run lint     # エラーがなければ OK
npm run dev      # http://localhost:5173 が開けば OK（止めるときは Ctrl+C）
```

`.env.local` の確認（値は表示せず、変数名だけ見る）：

```sh
# Mac
grep -o '^VITE_[A-Z_]*' .env.local
```

```powershell
# Windows（PowerShell）
Select-String -Path .env.local -Pattern '^VITE_[A-Z_]*' | ForEach-Object { $_.Matches.Value }
```

`VITE_SUPABASE_URL` と `VITE_SUPABASE_ANON_KEY` の2つが出れば OK。
